# RPi Camera Comparator - 디자인 아이디어 브레인스토밍

## 선택된 디자인 철학: **Precision Engineering Aesthetic**

기술 사양을 다루는 도구이므로, 정확성, 명확성, 그리고 전문성을 시각적으로 표현하는 디자인을 채택합니다.

### 핵심 원칙
1. **데이터 중심 레이아웃:** 정보 계층이 명확하고, 비교 데이터가 한눈에 파악되도록 구성
2. **기술적 우아함:** 미니멀한 라인, 정확한 타이포그래피, 그리드 기반 구조
3. **인터랙티브 피드백:** 선택이 즉시 시각적으로 반영되어 사용자의 선택을 강화
4. **신뢰성 표현:** 검증된 수치, 명확한 판정 기준, 투명한 계산 로직

### 색상 철학
- **주색:** 진한 파란색 (RGB 30, 58, 138) - 기술, 신뢰, 정밀성 상징
- **강조색:** 주황색 (RGB 255, 127, 0) - 경고, 최적화, 선택 강조
- **배경:** 거의 흰색 (RGB 248, 250, 252) - 데이터 가독성 극대화
- **텍스트:** 진한 회색 (RGB 20, 25, 40) - 높은 대비, 읽기 용이

### 레이아웃 패러다임
- **3단 구조:** 좌측 선택 패널 | 중앙 비교 테이블 | 우측 성능 시각화
- **카드 기반 컴포넌트:** 각 센서/렌즈 조합을 명확한 경계로 구분
- **동적 그리드:** 선택에 따라 결과가 실시간으로 업데이트

### 시그니처 요소
1. **성능 게이지:** 100m 식별/300m 인식 달성도를 원형 게이지로 표현
2. **PPM 시각화:** 막대 그래프로 거리별 픽셀 밀도 비교
3. **추천 배지:** "최적", "적정", "부족" 상태를 명확한 배지로 표시

### 인터랙션 철학
- **즉각적 반응:** 드롭다운 선택 후 0.3초 이내 결과 업데이트
- **상태 피드백:** 호버 시 미묘한 그림자 및 배경색 변화
- **비교 강조:** 선택된 항목은 강조 색상으로 하이라이트

### 애니메이션 가이드
- **진입 애니메이션:** 페이지 로드 시 카드들이 위에서 아래로 부드럽게 나타남 (300ms)
- **상태 변화:** 선택 변경 시 결과 영역이 페이드 인/아웃 (200ms)
- **호버 효과:** 마우스 오버 시 카드가 약간 올라오고 그림자 증가 (150ms)

### 타이포그래피 시스템
- **제목:** Roboto Bold 28px - 강한 시각적 계층
- **소제목:** Roboto Medium 16px - 섹션 구분
- **본문:** Roboto Regular 14px - 높은 가독성
- **데이터:** Roboto Mono 13px - 기술적 정확성 표현

## 최종 선택 이유

이 디자인은 **기술 사양 비교 도구**의 본질을 반영합니다. 사용자는 정확한 수치를 신뢰하고, 선택의 결과를 즉시 확인하고 싶어합니다. Precision Engineering Aesthetic은 이러한 요구를 시각적으로 충족시킵니다.
